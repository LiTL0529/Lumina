# 老式针式打印机（241×140mm / 241×93mm）配置与静默套打指南

各区域服务商仓库多使用老式针式打印机（如爱普生 LQ-630K / 映美 FP-630K / 得实 AR-520 等，USB 直连电脑，不支持蓝牙）。按本手册 3 分钟即可完成精准零偏移套打配置：

## 1. Windows 注册自定义联单纸型（防止连打第 2 张起走纸漂移）

1. 打开 `控制面板` → `设备和打印机`，选中已安装的针式打印机。
2. 点击顶部菜单栏 **打印服务器属性** → 勾选 **创建新表单**：
   - **二等分三联单**：表单名 `Lumina_241x140`，宽度 `24.10 cm`，高度 `14.00 cm`，边距全 `0.00 cm` → 点击保存表单。
   - **三等分短联单**：表单名 `Lumina_241x93`，宽度 `24.10 cm`，高度 `9.30 cm`，边距全 `0.00 cm` → 点击保存表单。
3. 右键该打印机 → **打印首选项** → 纸张规格选择刚刚创建的 `Lumina_241x140` 并设为默认。

## 2. 安装本地免费静默打印客户端（electron-hiprint）

1. 在库管 Windows 电脑上下载安装开源免费客户端 **`electron-hiprint`**（默认监听 `127.0.0.1:17521`，勾选“开机自启”）。
2. 打开浏览器进入 **Lumina PC 仓管系统** → 「销售出库与套打」→ 点击任意单据的 **针式打单**。
3. 页面顶部状态栏将自动显示绿色的 **`本地打印桥已连`**，选择对应的针式打印机即可一键静默打印指定份数（无浏览器弹窗干扰）。

## 3. 调整打印显示列（无需修改代码）

进入「商品与规则设置 → 针式套打模板与字段勾选」，按需勾选或取消显示：单价、折扣、折后价、上次欠款、单据备注等，点击保存后系统自动重新计算毫米级列宽。

# Lumina 一物一码仓库扫码作业 SOP

## 1. 工厂批次赋码与装箱

1. 品牌总部在「一物一码溯源 → 生成工厂防伪码批次」选择 SKU、数量与箱规（如 6 盒/箱或 24 盒/箱），生成不可预测的 16 位 HMAC 加密防伪码。
2. 点击 **导出 CSV** 发给印刷厂/包材厂排版贴标（含外箱码链接与对应单品盒码链接）。

## 2. 总仓扫码入库与发往服务商

- **整箱入库**：进入「采购与扫码入库 → 总仓工厂货扫码入库」，用 USB 扫码枪扫 **1 次外箱码**，系统自动展开并入库下属全部单品盒码，听到“嘀”声即成功，无需逐盒扫描。
- **总仓出库**：服务商下单（或总部代建 `总仓→服务商` 供货单）后，总仓在「销售出库与套打」点 **扫码出库**，扫外箱码即可整箱发往该服务商，系统自动记录 `assignedDealerId` 并触发针式套打。

## 3. 服务商扫码收货与出库机构

- **收货入仓**：服务商库管在「采购与扫码入库 → 服务商独立仓扫码收货」扫外箱码确认收货，库存立即进入服务商独立仓。
- **拆箱单盒出库**：服务商给终端机构开单后，若从整箱中拆出单盒扫码出库，系统将自动将对应外箱码标记为 **`UNPACKED`（已拆箱）** 并锁定防再次整箱扫描；同时若该机构处于 **90 天报备保护期**，本次有效扫码出库将自动将其转正为 **正式绑定机构（启动 270 天复购周期）**。
- **异常拦截**：若服务商误扫归属其他服务商的码，系统立即蜂鸣报错并向总部推送 `UNAUTHORIZED_SCAN` 高危风控预警。

## 4. 退货回仓与月度流向核验

- **退货回仓**：退货必须逐盒扫描原单品防伪码回仓，系统自动解除该码下游机构归属并恢复为在库状态。
- **月度核验**：每月初总部生成各服务商月度核验单，服务商提报实盘数；出现差异自动标红，总部流向管控负责人可一键发起复盘、调价或**立即暂停供货（冻结下单权限）**。
